# Sécurité

Pour signaler une faille, utiliser le signalement privé de GitHub : onglet « Security » du dépôt, puis « Report a vulnerability ». Merci de ne pas ouvrir de ticket public avant qu'un correctif soit publié.

Les mesures de sécurité de geocrowd sont décrites dans la section « Sécurité » du [README](README.md).
